# إدارة العهدة — تطبيق نظام إدارة العهدة المالية

غلاف تطبيق (PWA) لـ **نظام إدارة العهدة المالية** المبني على Google Apps Script، بنفس «نمط التطبيق» المعتمد لأنظمة مستشفى الحرم.
ينثبّت على أندرويد وآيفون والكمبيوتر بأيقونة المحفظة، ويفتح بشاشة كاملة على تسجيل الدخول مباشرة.

**رابط التطبيق:** `https://alharamhosmed-spec.github.io/haram-custody/`

© جميع الحقوق الفكرية محفوظة — مدير إدارة المشاريع: م. أحمد بندر الردادي · مستشفى الحرم

## الإعداد (مرة واحدة)
1. النظام **v5.1 أو أحدث** (فيه `setXFrameOptionsMode(ALLOWALL)` ووضع التطبيق `?app=1`).
2. النشر: التنفيذ باسم **أنا** · الوصول **أي شخص**.
3. رابط `/exec` في `index.html` ← `APP_CONFIG.GAS_URL`.

## التثبيت
- **أندرويد:** افتح الرابط في Chrome ← «تثبيت التطبيق».
- **آيفون:** افتح الرابط في Safari ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
- **الكمبيوتر:** أيقونة التثبيت في شريط العنوان (Chrome / Edge).

## مزايا
- شاشة إقلاع بهوية الحرم، وحالات واضحة لـ «لا يوجد اتصال» و«التحميل بطيء».
- التخزين المحلي للغلاف ببادئة `haramCustody_` حتى ما يتداخل مع باقي التطبيقات على نفس النطاق.
- الـ Service Worker يخزّن الغلاف فقط — **لا يخزّن أي بيانات مالية**، البيانات دائماً مباشرة من السيرفر.

## التحديثات
- تعديل النظام نفسه: انشره كـ **New version على نفس النشر** — ما تحتاج تلمس GitHub.
- تعديل الغلاف: عدّل الملف وزِد `VERSION` في `sw.js`.
- الأيقونة: `python3 tools/make_icons.py wallet`
